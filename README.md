# Wireless Signal Orchestra

BLEの受信信号強度（RSSI）を音と映像に変換する、参加型インタラクティブメディアアート作品です。参加者がスマートフォンを持って移動すると、電波の強さの変化が音と映像の変化として表れ、複数人で一つの作品をつくります。

## 想定構成

- PC 1台＋スマートフォン2〜5台。
- BLE RSSIを入力として取得し、端末ごとの信号の変化を扱います。
- Web Audio APIで音高・音量・音色などを制御します。
- 複数端末の信号をリアルタイムに可視化します。

## 今後の実装予定

1. PC・スマートフォン間のBLE通信方式と、RSSI取得方法・対応環境を検証する。
2. 複数端末の識別、RSSIの平滑化、PCへのデータ集約を実装する。
3. RSSIから音へのマッピングとリアルタイム可視化を実装する。
4. 2〜5台のスマートフォンを用いた参加体験を調整する。

RSSIは周囲の環境や端末の向きにも影響されるため、厳密な距離ではなく表現の入力として扱います。

現在はリポジトリの初期準備のみです。アプリ本体・テスト・CI・GitHub Pagesは未作成で、次のCodex Cloudセッションで実装を進めます。
